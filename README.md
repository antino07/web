A fully responsive, frontend-only Minecraft e-commerce storefront. It features a dynamic cart system, multiple themes, synthesized retro sound effects, and direct Telegram checkout integration.

## ✨ Features

- **🛒 Dynamic Cart System:** Add accounts to the cart, remove items, and calculate totals automatically.
- **🎨 4 Unique Themes:** Switch instantly between Modern Dark, Minecraft Pixel, Cyber Neon, and Clean Luxury.
- **🔊 Synthesized SFX Engine:** Uses the Web Audio API to generate retro sound effects (clicks, cart dings, level-up fanfare) without needing any audio files.
- **📱 Fully Responsive:** Includes a beautiful "Mobile Frame" toggle and a dedicated mobile menu.
- **✈️ Telegram Integration:** 
  - Capes use a "Buy Now" button that redirects directly to a Telegram bot with a pre-filled message.
  - Cart checkout generates a formatted order summary and sends it to the admin's Telegram.
- **🔍 Real-time Search:** Filters products instantly as you type.
- **📦 Downloadable Assets:** Includes a section for free PvP texture packs and maps.
- **📱 Social Media Hub:** Dedicated page to link YouTube and TikTok channels.
